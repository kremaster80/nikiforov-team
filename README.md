# NIKIFOROV TEAM — production-ready landing

Готовый адаптивный лендинг в серо-чёрно-голубом визуальном стиле с реальными материалами из исходного архива.

## Что уже сделано
- desktop / tablet / mobile адаптив;
- sticky header + mobile menu;
- hero с реальным фото Дмитрия;
- интерактивная карусель целей;
- два формата ведения и сравнительная таблица;
- 6 блоков состава продукта;
- команда, доказательства экспертизы, конкурсы, FAQ;
- scroll reveal-анимации, hover-эффекты, параллакс карточек на первом экране;
- mobile sticky CTA;
- prefers-reduced-motion для доступности;
- изображения локальные, поэтому страница может быть размещена на любом обычном хостинге.

## Запуск локально
Откройте `index.html` в браузере либо запустите простой HTTP-сервер:
`python -m http.server 8080`

## Перенос на Tilda
Самый надёжный вариант — сохранить страницу как отдельный путь/поддомен и связать её с Tilda. Если требуется именно внутри Tilda:
1. Создать новую страницу `online` / `project`.
2. Добавить один HTML-блок T123.
3. Вставить разметку из `tilda/T123.html`.
4. CSS из `tilda/tilda.css` добавить в Настройки страницы → Дополнительный CSS либо отдельным T123 в `<style>`.
5. JS из `tilda/tilda.js` добавить перед `</body>` в Дополнительный HTML.
6. Загрузить изображения из `assets/` в Tilda и заменить `{{ASSET_*}}` на получившиеся URL. Карта замены лежит в `tilda/ASSETS.md`.
7. Добавить пункт меню на новую страницу и опубликовать.

Важно: из этого окружения нет доступа к вашей панели Tilda, поэтому физически нажать Publish/заменить текущую страницу в аккаунте я не могу. Код уже подготовлен для переноса без переработки дизайна.
