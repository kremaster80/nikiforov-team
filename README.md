# Nikiforov Team v2

Переработанная версия основной страницы с учётом уточнений заказчика.

## Что изменено
- Убраны фотографии команды и других тренеров.
- Убраны дипломы, семинары и любые блоки, относящиеся к колледжу.
- Дмитрий Никифоров — единственное публичное лицо страницы.
- Архитектура продукта: микрообучение / микрокурсы + полноценное ведение.
- Добавлена ссылка на присланный Instagram Reel как пример контента.
- Сохранена основная логика ТЗ по полноценному ведению: тренировки, питание, техника, контроль и корректировки.
- Адаптивная мобильная версия и sticky CTA.

## GitHub Pages
В корне репозитория должны лежать `index.html`, `styles.css`, `app.js` и папка `assets`.

```bash
git add .
git commit -m "Rebuild Nikiforov Team product structure"
git push
```

## Tilda
Страницу можно перенести в T123/Zero Block частями. Для production на Tilda изображения лучше загрузить в Tilda/CDN и заменить локальный путь `./assets/dmitry.jpg` на полученный URL.

## Важно
Цена 14 000 ₽ взята из ранее переданного ТЗ для полноценного ведения. Цена микрообучения намеренно не придумана — её нужно подставить после финального согласования продукта.
